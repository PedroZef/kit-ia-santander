# Checklist: Pare, Confira, Use

Antes de usar uma resposta da IA.

## 1. Pare

- [x] Qual o impacto se estiver errado? *(Risco mitigado: o plano de estudos está estritamente alinhado com a ementa oficial da prova Oracle e princípios comprovados de Prompt Engineering)*
- [x] É uma decisão importante? *(Sim: envolve horas de dedicação e preparação para certificação técnica)*
- [x] Pode gerar prejuízo? *(Não: todas as ferramentas e técnicas recomendadas utilizam camadas gratuitas/acessíveis)*
- [x] Envolve outras pessoas? *(Sim: colegas que consultarem o repositório ou avaliadores da DIO)*

## 2. Confira

- [x] Os fatos estão corretos? *(Sim: arquitetura OCI GenAI, modelos Cohere Command R/R+, Llama 3 e tipos nativos de vetores no Oracle 23ai)*
- [x] Os números fazem sentido? *(Sim: 60 minutos diários divididos em 15m teoria, 35m prática e 10m validação; totalizando 7 horas)*
- [x] Datas e nomes estão corretos? *(Sim: códigos dos exames 1Z0-1127 e 1Z0-1122 e terminologias de PEFT: LoRA e T-Few)*
- [x] As fontes existem e sustentam a afirmação? *(Sim: fundamentado na documentação oficial da Oracle Cloud e literatura de LLMs)*
- [x] O contexto foi interpretado corretamente? *(Sim: respeito integral às restrições do usuário e aos frameworks do kit de IA)*

## 3. Use

Depois da revisão:

- use com mais confiança;
- reconheça os limites;
- assuma a responsabilidade pela decisão final.

**Provável não é o mesmo que verdadeiro.**
